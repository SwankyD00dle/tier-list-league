# @tier-list-league/frontend

Next.js (App Router) + React + Tailwind CSS.

## Develop the full app

From the repository root:

```bash
nvm use
npm install
npm run dev
```

Open http://localhost:3000. Next.js serves the frontend and proxies `/api/*` to the backend, so frontend code should use the typed `api` client. For a plain fetch or OAuth anchor, use `apiUrl(routes.users)` / `apiUrl(routes.discordAuth)` to retain the configured public prefix.

`BACKEND_URL` controls the internal proxy destination and defaults to `http://localhost:3001`. See `.env.example`.

## Scripts

- `dev` — start only the Next dev server.
- `build` / `start` — production build and serve.
- `typecheck` — type-check with TypeScript 7 (`tsc-native`).
- `test` — focused public URL, rewrite configuration, API fetch, and OAuth URL tests.
- `test:production` — build and serve real production Next instances at root and `/ingress/app-19`, checking pages, all referenced JS/CSS assets, API and OAuth callback rewrites (including query preservation) against a local mock backend. Requires no database or Discord credentials; replaces `.next` and uses temporary loopback ports. Each build has a three-minute timeout.

## Notes

- Styling uses Tailwind CSS v4 via `@tailwindcss/postcss`; global styles live in `app/globals.css`.
- Type-checking runs on TypeScript 7. Next's own toolchain still resolves `typescript` 5.9 (Next needs the TS compiler API, which the native TS 7 package does not expose until 7.1), so both are declared intentionally.

## Production behind an ingress prefix

Set `APP_PUBLIC_URL` to the **full externally reachable app URL**, for example
`https://example.com/ingress/my-app`, in the frontend environment for **both build and start**.
Next derives `basePath` (`/ingress/my-app`) and the client API prefix from this single value.
An origin with no pathname, or an unset variable for existing root-routed setups, produces
an empty base path. One trailing slash is accepted. Invalid URLs, credentials, queries,
fragments, noncanonical paths (dot segments, repeated slashes), and path segments outside
URL-unreserved characters (`A-Z a-z 0-9 - . _ ~`) fail configuration instead of losing the prefix.

```bash
APP_PUBLIC_URL=https://example.com/ingress/my-app npm run build --workspace @tier-list-league/frontend
APP_PUBLIC_URL=https://example.com/ingress/my-app npm run start --workspace @tier-list-league/frontend
```

- The ingress must forward the **entire pathname** to Next. Do not strip the prefix.
- Keep `BACKEND_URL` as the internal backend origin (default `http://localhost:3001`), without
  the public prefix. Next automatically prefixes rewrite sources: `/ingress/my-app/api/health`
  is forwarded internally to `/api/health`. It also prefixes Next static assets and `next/link`
  destinations, so keep `<Link href="/game">` unprefixed to avoid double-prefixing.
- Plain anchors and fetch do not get Next's prefix handling; use `apiUrl` with the existing
  unprefixed `routes`. Leave `NEXT_PUBLIC_API_BASE_URL` unset or empty for same-origin calls.
  An explicit nonempty value remains a complete API base override, not a frontend prefix.
- `NEXT_PUBLIC_BASE_PATH` is generated by Next configuration; do not configure it separately.
  `basePath` and browser URLs are baked into the bundle: **rebuild when APP_PUBLIC_URL's
  pathname changes**; changing only the runtime environment cannot relocate an existing build.
- Configure backend `FRONTEND_URL=https://example.com/ingress/my-app` and
  `DISCORD_REDIRECT_URI=https://example.com/ingress/my-app/api/auth/discord/callback`.
  Register that exact callback in Discord and enable secure cookies for HTTPS. The deployment
  tool supplies these backend values from the same full public URL. Callback success and
  cancellation preserve the prefix; authentication cookies with `Path=/` also cover it.

These local tests are not deployment verification: after manual merge, operations must deploy
clean current main, confirm real database/API/frontend/proxy readiness, and verify the exact
served SHA through the full external prefixed URL. A mocked rewrite is not real Discord login
or database-health evidence.
